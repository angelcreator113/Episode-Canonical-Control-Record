# Style Templates: Evoni's reference files

`LaLa_Canva_Style_Sheets.pptx` holds Evoni's five Canva Style Sheet templates (portrait), added 2026-10-14 (Task #3168). They are the **visual target** for the five masters in the Style Templates spec, `docs/design/2026-10-style-templates.md` §3. The spec is the rule: these slides show the look.

Every slide shares:
- the header "STYLING ADVENTURES with LaLa";
- an episode line;
- the footer "LaLaVerse • FASHION / ATTENTION / MONEY";
- a page number.

"ADD PHOTO" marks each photo spot. In the built templates it appears only in the editor, never in an export (spec §2 Rule 2).

| Slide | Template | Its spots |
|---|---|---|
| 1 | **The Episode Look** | Hero / Lala; Venue; Fashion inspiration; The look • three angles (Front, Side, Back); Wardrobe breakdown (Outfit, Shoes, Purse, Jewelry, Hair, Perfume, Nails) |
| 2 | **The Style Diary** | "A little fashion. A lot of story."; Main outfit; Detail shot; Venue mood; The details (Shoes, Bag, Jewelry, Beauty); Style notes / caption |
| 3 | **Runway to Reality** | "LOOK · CITY · OCCASION"; Full body hero; Outfit detail; Back view; The finishing touches (Shoes, Purse, Accessories, Hair) |
| 4 | **The Color Story** | "MOOD • TEXTURE • SILHOUETTE"; Main look; Venue / setting; Inspiration; Palette; Beauty + accessories (Hair, Makeup, Nails, Jewelry, Bag); Episode mood |
| 5 | **Invited to Slay** | Event name / host / Dream City; Date • dress code • vibe; Lala final look; Event venue; Fashion reference; Look checklist (Outfit, Shoes, Bag, Jewelry, Hair, Perfume, Nails); Caption / style rating / story note |

**What the file contains.** It was made with PptxGenJS: shapes and text only, with no embedded photos and no outside links. Its metadata author is "Prime Studios". It was checked before it was committed, because this repository is public.
